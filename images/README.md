# FHSE Local Images

This folder centralizes locally generated FHSE release binaries across targets.

Examples:

- `images/Raspberry/`
- `images/VM/`
- `images/PC/`

Repository policy:

- generated binaries are intentionally excluded from Git
- tracked release metadata stays in:
  - `Raspberry/releases/`
  - `VM/releases/`
  - `PC/releases/`
