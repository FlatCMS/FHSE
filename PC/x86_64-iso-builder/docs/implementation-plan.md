# PC ISO Builder Implementation Plan

## Immediate objective

Use the shared FHSE core bundle as the application/runtime payload for the future x86_64 installer media.

## Planned next implementation steps

1. define the Ubuntu Server x86_64 base ISO workflow
2. define the autoinstall injection strategy
3. stage the shared FHSE bundle into the ISO workspace
4. define disk layout assumptions for dedicated PC installs
5. define the first validation matrix for NUC and legacy PC hardware
