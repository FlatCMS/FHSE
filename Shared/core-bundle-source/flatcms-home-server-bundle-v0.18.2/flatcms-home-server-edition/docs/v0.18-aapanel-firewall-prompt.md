# V0.18 - aaPanel firewall prompt

V0.17 fixed the first aaPanel prompt but aaPanel can later trigger UFW:

```text
Command may disrupt existing ssh connections. Proceed with operation (y|n)?
```

V0.18 changes the aaPanel installation step to:

```bash
yes y | bash install_panel_en.sh forum
```

It also pre-allows SSH before aaPanel changes the firewall policy:

```bash
ufw allow OpenSSH || ufw allow 22/tcp
```

This is intended for the Wizard Preview and first-boot USB workflow, where there is no interactive terminal attached to the installer.
