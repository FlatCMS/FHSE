# FlatCMS Home Server Edition V0.18.1

V0.18.1 reprend V0.18 comme source de vérité et ajoute uniquement le pilotage Wizard étape par étape.

## Modifications autorisées

- Interface FlatCMS Installer étape par étape.
- Exécution indépendante de chaque étape.
- Récupération et affichage des accès aaPanel.
- Boutons Copier corrigés.
- Espacement corrigé dans la colonne de progression.

## Garde-fous

- Ne pas déplacer `/www/wwwroot/default`.
- Ne pas créer de sauvegarde automatique de `/www/wwwroot/default`.
- Ne pas patcher globalement les root directives Nginx.
- Ne pas créer de `.flatcms-bak.*` sur les vhosts aaPanel.
- Ne pas modifier `0.default.conf`.

## Déploiement FlatCMS

FlatCMS est copié dans `/www/wwwroot/default` en conservant le dossier en place. Le site aaPanel utilise `/public` comme répertoire d'exécution.
