# V0.11 - Official aaPanel Website attempt

aaPanel documents a PHP Website API endpoint at `/v2/site?action=AddSite` with parameters such as `webname`, `path`, `type`, `version`, `port`, `ftp`, `sql`, `set_ssl`, and `is_create_default_file`.

The public HTTP API normally requires enabling API access in aaPanel Settings. For local first-boot installation, V0.11 instead tries the same internal Python flow used by aaPanel:

- `panel_site_v2.panelSite().AddSite(...)` to create the Website entry.
- `panelSite.panelSite().SetSiteRunPath(...)` to set `/public`.
- `vhost/rewrite/<site>.conf` to add the FlatCMS clean URL rewrite.

## Behavior

- Create the site with the local IPv4 address as domain by default.
- Use `/www/wwwroot/default` as site directory.
- Use `/public` as running directory.
- Use PHP version `85`.
- Do not create FTP, SQL, SSL, or default files.
- Keep the generated FlatCMS Nginx vhost and rewrite rule.

## Report values

| Key | Meaning |
| --- | --- |
| `AAPANEL_SITE_STATUS=official` | The site exists in aaPanel Website. |
| `AAPANEL_SITE_STATUS=manual-vhost` | The internal call failed; the generated vhost fallback was used. |
