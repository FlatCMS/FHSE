# V0.8 - aaPanel Default Site Routing

V0.8 keeps the aaPanel stack policy from V0.7:

- aaPanel is installed first;
- Nginx 1.24 is installed through aaPanel;
- PHP 8.5 is installed through aaPanel;
- Pure-Ftpd is skipped by default;
- FlatCMS is served through the aaPanel Nginx runtime.

The routing strategy changed to simplify the first Home Server experience.

Instead of creating a separate `/www/wwwroot/flatcms` site and a custom `00-flatcms-home-server.conf` vhost, FlatCMS now reuses the aaPanel default website slot:

```text
FLATCMS_WEB_ROOT=/www/wwwroot/default
FLATCMS_PUBLIC_ROOT=/www/wwwroot/default/public
FLATCMS_VHOST=/www/server/panel/vhost/nginx/0.default.conf
```

The full FlatCMS package is deployed into `/www/wwwroot/default`, but Nginx points only to `/www/wwwroot/default/public`.

This keeps FlatCMS internals outside the public document root while avoiding an extra site folder during the first installation.

The final HTTP healthcheck now tests the machine LAN URL, for example `http://192.168.1.40/`, instead of treating `http://127.0.0.1/` as the main truth. aaPanel owns localhost-only internal status vhosts, so loopback can behave differently from the URL opened by the user from another machine.
