# FHSE RC3.4 - Cloudflare Tunnel and PHP dependencies

RC3.4 adds:

- `libc-ares-dev` in the Ubuntu preparation step for aaPanel PHP 8.5 / curl build compatibility on Ubuntu 22.04 ARM64 / Raspberry Pi.
- Strict cleanup of incomplete `/www/server/php/85` directories before retrying PHP 8.5 installation.
- Real Cloudflare Tunnel service installation when `FLATCMS_ACCESS_MODE=cloudflare_tunnel` and `FLATCMS_CLOUDFLARE_TUNNEL_TOKEN` is provided.
- Product wording update: “Création de l’espace web / Dossier de stockage et vhost”.

The Cloudflare token must never be printed in report.env. The final report only stores Cloudflare status.
