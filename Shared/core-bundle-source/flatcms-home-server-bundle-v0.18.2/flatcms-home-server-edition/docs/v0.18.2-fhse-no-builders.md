# FHSE v0.18.2 — FlatCMS package without legacy builders

FHSE v0.18.2 uses the VM-validated installer engine.

For the Raspberry Pi image preparation, the bundled `packages/flatcms.zip` has been cleaned of the discontinued legacy builders:

- PagesBuilder
- MenuBuilder
- FooterBuilder

The installer logic is unchanged. Only the FlatCMS application package payload is changed.

The future product direction is Studio FlatCMS.
