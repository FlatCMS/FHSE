# V0.15 - aaPanel dict-like request object

V0.14 showed that aaPanel 8.0.4's `panel_site_v2.AddSite()` expects the request object to support dictionary-style calls:

```text
sub_dir = get.get('sub_dir', '')
AttributeError: 'Obj' object has no attribute 'get'
```

V0.15 changes the helper request object to subclass `dict` while preserving attribute access:

- `get.version`
- `get.get('sub_dir', '')`
- `get['sub_dir']`

The manual vhost fallback remains unchanged.
