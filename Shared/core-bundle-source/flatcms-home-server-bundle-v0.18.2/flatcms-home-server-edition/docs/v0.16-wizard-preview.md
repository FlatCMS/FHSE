# V0.16 - Wizard Preview

V0.16 adds a local web wizard preview without changing the validated V0.15 installation engine.

The wizard is started manually:

```bash
sudo ./start-wizard-preview.sh
```

It exposes:

```text
http://<vm-ip>:8080
```

Preview scope:

- hardware choice screen,
- basic FlatCMS configuration screen,
- install launch button,
- live status,
- install log viewer,
- final report viewer,
- FlatCMS access button.

Out of scope for V0.16:

- Cloudflare,
- Let's Encrypt,
- automatic USB first-boot service,
- graphical browser auto-launch on the server.

The future USB edition can reuse the same wizard server behind a systemd first-boot service.
