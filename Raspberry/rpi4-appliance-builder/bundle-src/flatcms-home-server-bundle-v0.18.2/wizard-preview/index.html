FlatCMS FHSE
Release Candidate RC3.13
Bienvenue

Bienvenue dans FlatCMS Home Server Edition

Cet assistant prépare votre serveur FHSE avec un environnement web complet pour installer FlatCMS en local. La publication de votre site web se fera depuis l'administration de FlatCMS via Cloudflare Tunnel.

Matériel flexible Compatible Raspberry Pi, VM ARM64 et futures déclinaisons FHSE.
Accès local immédiat Votre site est disponible sur votre réseau local à la fin de l’installation.
Installation guidée Chaque étape prépare automatiquement votre serveur FlatCMS.
Publication depuis FlatCMS La mise en ligne publique se pilotera ensuite depuis l’administration de FlatCMS.
Configuration

Configurer votre serveur FlatCMS

Renseignez les informations de base. Par défaut, votre site sera accessible en local sur votre réseau.

Accès technique Ubuntu

FHSE crée un compte technique de secours pour le diagnostic local ou SSH. L’identifiant reste fixé à admin, mais le mot de passe doit être choisi ici avant de lancer l’installation.

Définissez maintenant le mot de passe d’accès technique Ubuntu. Aucun mot de passe partagé n’est livré par défaut.
Compte technique admin
État SSH par mot de passe Désactivé tant que le wizard n’a pas validé le mot de passe
Utilisé pour configurer le serveur web FHSE avant l’installation de FlatCMS.
Minimum 8 caractères. Ce mot de passe sera appliqué au compte Ubuntu admin.
La publication de votre site web se fera depuis l'administration de FlatCMS via Cloudflare Tunnel.
Ubuntu Server est déjà intégré à l’image FHSE. L’assistant configure automatiquement les composants nécessaires au fonctionnement de FlatCMS.
