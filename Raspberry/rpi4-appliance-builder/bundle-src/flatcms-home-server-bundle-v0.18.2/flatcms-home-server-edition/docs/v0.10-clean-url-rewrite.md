# V0.10 - FlatCMS clean URL rewrite

V0.10 adds the FlatCMS rewrite rule validated in aaPanel Website settings.

## Rewrite rule

```nginx
location /{
    if (!-e $request_filename) {
       rewrite  ^(.*)$  /index.php/$1  last;
       break;
    }
}
```

The installer writes this rule to:

`/www/server/panel/vhost/rewrite/<site>.conf`

The generated Nginx vhost includes that file so FlatCMS gets clean URLs without manual aaPanel changes.

## PHP-FPM reload

After `fileinfo` is detected or built, the installer reloads PHP-FPM 8.5 and waits for `/tmp/php-cgi-85.sock` again. This ensures the web runtime sees `fileinfo`, not only the CLI runtime.
