# V0.12 - aaPanel Website import and FlatCMS routes

V0.12 addresses two field-test issues from V0.11:

- aaPanel 8.0.4 stores `panel_site_v2.py` in `/www/server/panel/class_v2`, so the helper must add that directory to `sys.path` before importing `panel_site_v2`.
- FlatCMS clean URLs use the aaPanel rewrite pattern that sends routes to `/index.php/<route>`, so the generated vhost must pass `PATH_INFO` to PHP-FPM.

Expected report values:

```env
AAPANEL_SITE_STATUS=official
CHECK_FLATCMS_ROUTE=ok
```

If aaPanel still refuses the internal Website creation, the installer keeps the generated vhost fallback and reports:

```env
AAPANEL_SITE_STATUS=manual-vhost
```
