# V0.6 aaPanel Auto Stack

## Goal

V0.6 installs the aaPanel runtime stack automatically instead of asking the user to install apps manually from aaPanel App Store.

## Internal aaPanel Command

aaPanel exposes an internal installer:

```bash
/www/server/panel/install/install_soft.sh
```

Syntax:

```bash
bash install_soft.sh 4 install nginx 1.24
bash install_soft.sh 4 install php 8.5
bash install_soft.sh 4 install pure-ftpd 1.0
```

## Stack

| Component | Expected path |
| --- | --- |
| Nginx 1.24 | `/www/server/nginx/sbin/nginx` |
| PHP 8.5 | `/www/server/php/85/bin/php` |
| PHP-FPM socket | `/tmp/php-cgi-85.sock` |
| Pure-Ftpd 1.0 | `/www/server/pure-ftpd/bin/pure-pw` |

## Pure-Ftpd Repairs

On a fresh Ubuntu VM, Pure-Ftpd can fail because:

- the system user `ftp` does not exist;
- `/etc/ssl/private/pure-ftpd.pem` does not exist.

V0.6 creates both automatically:

```bash
useradd -r -s /usr/sbin/nologin -d /var/ftp ftp
openssl req -x509 -nodes -newkey rsa:2048 \
  -keyout /etc/ssl/private/pure-ftpd.pem \
  -out /etc/ssl/private/pure-ftpd.pem \
  -days 3650 \
  -subj "/CN=localhost"
```

## Current Limitation

V0.6 still writes the Nginx vhost file directly. The next step is creating the website through aaPanel's Website API or internal Python model so the site appears fully managed in the aaPanel Website table.
