# V0.5 aaPanel Stack Test

## Goal

Validate FlatCMS Home Server Edition with the real aaPanel-managed stack:

- aaPanel 8.0.4;
- Nginx 1.24;
- PHP 8.5;
- Pure-Ftpd 1.0;
- FlatCMS deployed to `/www/wwwroot/flatcms`;
- document root set to `/www/wwwroot/flatcms/public`;
- PHP-FPM socket set to `/tmp/php-cgi-85.sock`.

## Required State Before Running V0.5

Install these components from aaPanel App Store:

- Nginx 1.24;
- PHP 8.5;
- Pure-Ftpd 1.0.

Verify from SSH:

```bash
/www/server/nginx/sbin/nginx -v
/www/server/php/85/bin/php -v
ls -la /tmp/php-cgi-85.sock
ls -la /www/server/pure-ftpd
```

## Run

```bash
unzip flatcms-home-server-bundle-v0.5.zip
cd flatcms-home-server-bundle-v0.5
./install-local-vm.sh
```

## Expected Report

```text
CHECK_AAPANEL=installed
CHECK_NGINX=ok
CHECK_NGINX_VERSION=nginx/1.24.0
CHECK_PHP85=ok
CHECK_PHP85_SOCKET=/tmp/php-cgi-85.sock
CHECK_PURE_FTPD=installed
CHECK_HTTP_LOCAL=ok
FLATCMS_PUBLIC_ROOT=/www/wwwroot/flatcms/public
FLATCMS_PHP_FASTCGI_PASS=unix:/tmp/php-cgi-85.sock
```

## Known Limitation

V0.5 writes the aaPanel Nginx vhost file directly. It does not yet create the website entry through aaPanel's own database/API, so the site may not appear fully managed in the aaPanel Website list.

The next step is to identify the official aaPanel local API or internal command for creating a PHP site with no database and document root `/public`.
