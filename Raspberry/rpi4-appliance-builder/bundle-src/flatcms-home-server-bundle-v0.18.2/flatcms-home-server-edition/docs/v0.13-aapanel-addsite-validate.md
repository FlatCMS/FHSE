# V0.13 - aaPanel AddSite validate field

V0.12 reached a working FlatCMS installation, including Nginx, PHP 8.5, `fileinfo`, and clean URLs.

The remaining aaPanel Website issue was:

```text
'Obj' object has no attribute 'validate'
```

V0.13 adds `validate=0` to the internal `AddSite` request object. The generated vhost fallback is unchanged and remains available if aaPanel still refuses the internal Website creation.

V0.13 also makes the final FlatCMS route healthcheck retry for a few seconds and accepts either:

- the `flatcms_session` cookie,
- `FlatCMS` in the page,
- `Installation` in the page.
