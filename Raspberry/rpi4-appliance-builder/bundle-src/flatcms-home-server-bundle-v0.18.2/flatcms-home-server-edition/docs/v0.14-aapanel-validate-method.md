# V0.14 - aaPanel validate method

V0.13 showed that aaPanel's internal `AddSite` path calls `get.validate(...)`.

The field-test error was:

```text
'int' object is not callable
```

V0.14 removes the scalar `validate=0` value and provides a permissive `validate(*args, **kwargs)` method on the local request object used by the installer helper.

The working manual vhost fallback remains unchanged.
