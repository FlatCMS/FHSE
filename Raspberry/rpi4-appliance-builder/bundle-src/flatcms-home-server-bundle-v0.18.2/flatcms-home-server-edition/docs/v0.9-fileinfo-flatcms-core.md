# V0.9 - FlatCMS Core and PHP fileinfo

V0.9 focuses on the field issues found during the aaPanel 8.0.4 VM tests.

## Changes

- Bundle the latest supplied FlatCMS Core package.
- Keep the default deployment target at `/www/wwwroot/default`.
- Keep the running directory at `/public`.
- Keep Pure-Ftpd disabled by default.
- Require PHP 8.5 `fileinfo`.
- Try to build `fileinfo` from `/www/server/php/85/src/ext/fileinfo` when it is missing.
- Remove immutable aaPanel `.user.ini` files before serving FlatCMS.
- Set `open_basedir` to the project root instead of the public directory.
- Use an IP/domain vhost file instead of binding the server IP in `0.default.conf`.

## Target stack

| Component | Version |
| --- | --- |
| aaPanel | 8.0.4 |
| Nginx | 1.24 |
| PHP | 8.5 |
| PHP extension | fileinfo |
| FTP | skipped by default |

## Manual fallback

If `fileinfo` still fails after automatic build, install it from:

`aaPanel > PHP-8.5 > Manage > Install Extensions > fileinfo`
