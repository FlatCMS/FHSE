# V0.18.2 — Correctif binding IP locale

Base : V0.18.1.

Objectif : corriger le cas où aaPanel affiche `Website not found` sur `http://IP_LOCALE/` alors que l’installation des composants a réussi.

Modifications autorisées :

- Détection IPv4 locale robuste via `detect_local_ipv4`.
- Ajout systématique de l’IP locale dans `server_name` du vhost FlatCMS.
- Healthcheck final réellement bloquant si `http://IP_LOCALE/` ne sert pas FlatCMS.
- Espacement renforcé entre titre et sous-titre dans la progression.

Modifications interdites respectées :

- Aucun déplacement de `/www/wwwroot/default`.
- Aucune sauvegarde `.flatcms-bak.*`.
- Aucun patch global des root Nginx.
- Aucun renommage du site default aaPanel.
