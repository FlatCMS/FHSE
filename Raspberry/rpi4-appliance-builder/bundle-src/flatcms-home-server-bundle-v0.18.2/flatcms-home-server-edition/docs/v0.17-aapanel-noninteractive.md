# V0.17 - aaPanel non-interactive install

V0.16 introduced the web Wizard Preview. During a wizard-driven install, the official aaPanel installer could block on:

```text
Do you want to install aaPanel to the /www directory now?(y/n):
```

Because the installer runs as a background process, there is no interactive terminal to type `y`.

V0.17 sends the expected confirmation automatically:

```bash
printf 'y\n' | bash install_panel_en.sh forum
```

This keeps manual SSH installation and wizard-driven installation aligned.
