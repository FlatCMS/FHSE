# V0.7 Routing Default

V0.7 keeps the validated aaPanel auto-install path but removes Pure-Ftpd from the default stack.

## Default Stack

- aaPanel 8.0.4
- Nginx 1.24
- PHP 8.5
- FlatCMS package

Pure-Ftpd is skipped by default with:

```env
FLATCMS_INSTALL_PURE_FTPD=0
```

## Routing Fix

The V0.6 test showed that Nginx still served aaPanel's default site from:

```text
/www/wwwroot/default
```

V0.7 fixes that by:

- disabling `/www/server/panel/vhost/nginx/default.conf` when present;
- replacing `/www/wwwroot/default` references with `/www/wwwroot/flatcms/public`;
- writing `/www/server/panel/vhost/nginx/00-flatcms-home-server.conf`;
- making that vhost listen on `80 default_server` when possible.

## Remaining Limitation

The site is still configured at Nginx level. It may not yet appear as a first-class aaPanel Website entry until we integrate aaPanel's Website API/model.
